# R-00352 report — Native Tick/Frame Timer Manager

## Status

Implemented in worktree `feat/r-00352-timer-manager`. Not pushed.

## Delivery

- `lumio-timer` crate: `TimerManager` core (one-shot / repeating / cancel / advance, generation-safe handles, CallbackSlot queue).
- `ClientTimerManager` / `ServerTimerManager` adapters (pre-registered `DispatchId`, no function pointers).
- Slice consumers: Bot chat cadence on Client (`BOT_CHAT_CADENCE_TICKS = 5`); server world-authority heartbeat on Server (`SERVER_WORLD_HEARTBEAT_TICKS = 10`).
- `HostTimerService`: wall-clock typed-command port for the five-minute reconnect window. Not the Tick/Frame manager.
- Frozen ABI mirror: `docs/architecture/wire/native-timer-abi-v1.json` @ `2b7e321`.
- `slot_queue_full` is a per-firing stable reject + timer terminal; manager continues; not process fail-stop.

## Tests

`cargo test -p lumio-timer`: 28 passed (ABI testCases/invalidCases, CallbackSlot failures, Bot/Server consumers, host reconnect split, generation overflow fail-stop).

Also: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo xtask check-dep-dag`, `cargo test -p xtask -- accepts_the_specified_dag v14_activity_refs_match_live_execution_truth`.

## Known gaps

- `node .spec/tools/spec-lint.mjs` reports unresolved `.claude/agents`, `.claude/skills`, `.agents/skills` symlinks on this Windows worktree (points at themselves). Not introduced by the timer crate.
- `HostTimerService` is a NativeCore stand-in of the host layer (R-00272/R-00350 domain), used to prove separation; it is not the C# host implementation.
- Generation overflow is process fail-stop via panic, not `std::process::abort`.
- Timer is in-process API only; `lumio-native-ffi` does not export it (ADR-055 / local ADR 0007).
